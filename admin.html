Informações Pessoais

Para adicionar sua foto, coloque uma imagem na pasta upload/foto-pessoal/
Nomes aceitos: foto.jpg, foto.png, foto.jpeg, image.jpg, image.png, image.jpeg

Projetos

📁 Como funciona:

1. Coloque até 5 imagens em cada pasta (projeto1 a projeto10) dentro de upload/
2. Edite o arquivo upload/projetos.json para configurar os detalhes
3. Clique em "Atualizar Projetos" para carregar as imagens
