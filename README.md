## 🔄 Arquitetura

```mermaid
flowchart LR
  Visitor([Visitante]) --> Pages[GitHub Pages]
  Pages --> Index[index.html]
  Index --> App[src/app.js MVC]
  App --> JSON[upload/*.json]
  App --> Views[Views / Controllers]
  Admin[admin.html] --> JSON
```

## ▶️ Quick start

```bash
git clone https://github.com/BrayanSilver/brayansilver.github.io.git
cd brayansilver.github.io
npx serve .
```

| Caminho | Finalidade |
|---------|------------|
| `upload/info-pessoal.json` | Bio, hero, skills |
| `upload/projetos.json` | Projetos |
| `upload/contato.json` | Contato |
| `admin.html` | Painel admin |
| `src/` | App MVC |
